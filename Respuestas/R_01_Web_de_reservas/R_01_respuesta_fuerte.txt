Introducción
Tu proyecto encaja perfectamente con PHP puro + MySQL + HTML/CSS/JavaScript.
No necesitas React: es un sistema basado en formularios, y PHP está diseñado justo
para eso. Añadir React solo te complicaría con un paso de compilación que no aporta nada
aquí.

Todo el código funciona en XAMPP con PHP 7.4+ o 8.x.

Lo siguiente que me ha dado la IA son unos puntos a seguir:
1. Estructura de carpetas -> aquí me ha dado como dice el nombre la estructura
de todo el proyecto con sus respectivas carpetas y archivos.

2. Script SQL -> Aquí crea la base de datos en PHPmyAdmin y ejecuta el código
propuesto.
3. Código principal -> Lo que me ha dado es el código en el cual se va a basar el
proyecto y dentro de este hay 6 puntos que va siguiendo a la perfección.
4. Estilos responsive (assets/css/style.css) -> Aquí va el código del css.
5. README -> Aquí te explica los pasos a seguir para la puesta en marcha del
XAMPP.
