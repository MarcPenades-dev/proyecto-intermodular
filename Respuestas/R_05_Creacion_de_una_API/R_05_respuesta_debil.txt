 Próximos pasos recomendados
1. **Base de datos**: MongoDB (Mongoose), PostgreSQL (Prisma/Sequelize) o MySQL.

2. **Validaciones**: usa `zod` o `joi`.
3. **Autenticación**: JWT con `jsonwebtoken` y `bcrypt`.
4. **Variables de entorno**: `dotenv` para configuración.
5. **Documentación**: `swagger-ui-express` para OpenAPI.
