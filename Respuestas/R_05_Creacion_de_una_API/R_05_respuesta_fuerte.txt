Deepseek
 API REST para Gestión de Tareas de Almacén
Explicación breve
Vamos a construir una API REST con **Node.js + Express + MongoDB (Mongoose)**
siguiendo una arquitectura por capas (routes → controllers → models). La API
gestionará **tareas de almacén** (recepción, picking, packing, inventario, etc.) con un
CRUD completo. Usaremos `dotenv` para variables de entorno, `cors` para permitir
peticiones desde el frontend y un middleware centralizado de errores con códigos HTTP
correctos (200, 201, 400, 404, 500).
